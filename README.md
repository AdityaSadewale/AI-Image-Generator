# 🎨 AI Image Generator

Welcome to **AI Image Generator**! 🚀 This project lets you create stunning AI-generated images from text prompts using modern AI models. Perfect for creatives, designers, and AI enthusiasts! 🧠✨

---
## 🌈 Features

- 🧊 **Glassmorphism Cards** – Beautiful frosted-glass style image cards  
- ⚡ **Animated Gradient Background** – Smooth and eye-catching  
- 🖼 **Fullscreen Modal Preview** – Click images to view in full screen  
- 🪄 **Particle Effects** – Floating particles for a magical touch  
- 📌 **Masonry Layout** – Pinterest-style responsive image grid  
- 🧠 **AI Image Generation** – Powered by Gemini API (or your preferred AI model)  
- ⏳ **Loading Animation** – Smooth skeleton and spinner while generating images  
- 🌙 **Dark Mode** – Switch between light & dark themes effortlessly  
- 🎛 **Customizable** – Choose model, image count, and aspect ratio  

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3 (Glassmorphism, CSS animations), JavaScript  
- **Icons:** Font Awesome 6  
- **API:** Gemini AI API (or compatible AI image generation API)

## ⚡ How to Use

1. Clone the repository:

```bash
git clone https://github.com/AdityaSadewale/AI-Image-Generator.git
Navigate to the project folder:

cd AI-Image-Generator
Open index.html in your browser.

Select an AI model, number of images, aspect ratio, and type your prompt.

Click Generate to create your AI-powered images.

Click any image to view it in fullscreen and download it.
